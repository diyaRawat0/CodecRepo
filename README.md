# Full-Stack Projects

A collection of full-stack applications built using modern web technologies, focusing on backend development, database management, REST APIs, and user-friendly interfaces.

## Projects

### 1. Online Quiz System

A backend-focused quiz application with secure question handling, server-side timer control, automatic submission, and result management.

**Tech Stack:**
React.js · Node.js · Express.js · MySQL

**Key Features:**

* Server-controlled timed quizzes
* Secure question and answer management
* Automatic score calculation
* User attempt and result tracking
* Admin quiz management
* MySQL relational database
* Input validation and error handling

---

### 2. E-Commerce Product Catalog

A product catalog application with search, filtering, pagination, and optimized database queries.

**Tech Stack:**
React.js · Node.js · Express.js · MongoDB

**Key Features:**

* Product listing
* Advanced search and filtering
* Category-based organization
* Backend pagination
* MongoDB indexing
* REST API integration
* Data validation and sanitization

---

### 3. Student Management System

A student management application for handling student, course, department, and enrollment records.

**Tech Stack:**
React.js · Node.js · MySQL

**Key Features:**

* Student record management
* Full CRUD operations
* Course and department management
* Relational database design
* Search and sorting
* Parameterized SQL queries
* Frontend and backend validation

---

## Technologies Used

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Databases:** MySQL, MongoDB
* **APIs:** REST API
* **Development:** Git, GitHub
